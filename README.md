# LUMÉA

LUMÉA is a responsive luxury beauty studio website focused on elegant presentation, service discovery, bridal offerings, portfolio content, and booking interactions.

## Features

- Responsive single-page layout
- Luxury beauty studio visual direction
- Services and bridal sections
- Studio and portfolio presentation
- Booking form interactions
- Smooth front-end reveals and transitions
- Mobile-friendly navigation and layout

## Built With

- HTML
- CSS
- JavaScript
